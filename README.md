# Presenter

**Presenter** (prononcé « prézenteur », /pɹɪˈzɛntəɹ/) est un éditeur natif de présentations pour les oraux techniques. Composez vos diapositives avec du Markdown, des images et des blocs de code. Dans **Code Flow**, utilisez JavaScript pour faire apparaître les éléments et déclencher vos animations au rythme de la présentation.

Avec le SDK .NET 10, lancez `dotnet run --project src/Presenter`. Sur macOS, `./build-macos.sh` produit `build/Presenter.app`.
